走近细胞

细胞学说 · 生命系统的结构层次 · 病毒 · 真核细胞与原核细胞 · 显微镜使用

1.1 细胞学说

  • 建立者：施莱登、施旺（提出）；魏尔肖补充「细胞通过分裂产生新细胞」。
  • 内容（三点）：①细胞是一个有机体，一切动植物都由细胞发育而来，并由细胞和细胞产物构成；②细胞是一个相对独立的单位，既有自己的生命，又对与其他细胞共同组成的整体生命起作用；③新细胞是由老细胞分裂产生的。
  • 意义：揭示细胞的统一性和生物体结构的统一性（证明动植物有共同的结构基础与亲缘关系）。
  • 局限：未涉及原核生物、真菌、病毒；未揭示细胞的多样性。
  • 启示：科学发现离不开技术支持；理论经修正补充而完善；运用了不完全归纳法——结论可信但可能有例外。

1.2 生命系统的结构层次

  • 层次：细胞 → 组织 → 器官 → 系统 → 个体 → 种群 → 群落 → 生态系统 → 生物圈。
  • 植物没有「系统」层次（六大器官直接构成个体）；单细胞生物没有组织、器官、系统层次，细胞层次即个体层次；病毒没有结构层次（不属于生命系统的任何层次，但属于生物）。
  • 生态系统包括生物群落与非生物的环境（阳光、空气、水等），仍属于生命系统。
  • 细胞是最基本的生命系统：单细胞生物一个细胞完成全部生命活动；多细胞生物依赖各种分化的细胞密切合作。

1.3 病毒

  • 结构：核酸（DNA 或 RNA）+ 蛋白质；无细胞结构，必须寄生在活细胞中才能增殖（培养病毒须用活细胞/活鸡胚，不能用普通培养基）。
  • 分类：DNA 病毒（T2 噬菌体、乙肝病毒）；RNA 病毒（HIV、流感病毒、SARS 冠状病毒、新冠病毒）。RNA 病毒遗传物质一般为单链，结构不稳定、易变异，疫苗研发难度大。
  • 增殖过程：吸附 → 注入核酸（噬菌体注射式；动物病毒多经膜融合或胞吞）→ 合成核酸与蛋白质 → 组装 → 释放。合成场所利用宿主细胞的核糖体、原料和能量。

  • 蓝细菌（原核）：含叶绿素和藻蓝素，能进行光合作用，但没有叶绿体。
  • 质粒：小型环状 DNA，存在于绝大多数原核生物中，酵母菌中也存在；是基因工程的常用载体。
  • 常见原核生物：蓝细菌（念珠藻、色球藻、颤藻、发菜）、大肠杆菌、乳酸菌、硝化细菌、醋酸杆菌、根瘤菌、支原体（原核中唯一无细胞壁）。带「菌」字的多为细菌，但酵母菌是真核生物。
边角小字
  • 显微镜下识别真核与原核细胞：有无以核膜为界限的细胞核（教材第 11 页图示比较）。
  • 水华与赤潮：水体富营养化（N、P 含量高）导致蓝细菌和绿藻等大量繁殖，淡水称水华，海水称赤潮。
  • 科学史：列文虎克发现活细胞（红细胞、精子）；罗伯特·胡克发现并命名「细胞」（死细胞）；施莱登提出植物体由细胞组成；施旺提出动物体也由细胞组成。
易错警示
  • 病毒不属于生命系统的任何结构层次，但病毒属于生物。
  • 细胞融合（如人鼠细胞融合）也能产生新细胞——「新细胞只能由细胞分裂产生」的说法不对。
  • 原核细胞≠低等细胞：原核与真核细胞的根本区别是有无以核膜为界限的细胞核，本质是遗传物质存在形式不同。
  • 蓝细菌能进行光合作用却没有叶绿体；硝化细菌能进行化能合成作用；醋酸杆菌无线粒体却可进行有氧呼吸（酶分布在细胞膜上）。
  • 二分裂不是减数分裂也不是有丝分裂，原核细胞的分裂不遵循孟德尔定律。
高频考点 · 显微镜使用
  • 换高倍镜：只调细准焦螺旋，不动粗准焦螺旋；先在低倍镜下将目标移到视野中央。
  • 物像移动：显微镜成倒立的虚像，物像偏哪往哪移（欲将左上方物像移至中央，装片向左上方移）。
  • 视野中污点定位：转动目镜（动→在目镜）、换物镜（消失→在物镜）、移动装片（动→在装片）。
  • 视野内细胞数目计算：目镜 10×、物镜 10× 时圆形视野中有 64 个充满视野的细胞，换 40× 物镜后为 64 ÷ 16 = 4 个；若细胞呈单行排布，则按长度计算 16 ÷ 4 = 4 个。
  • 放大倍数指长度放大，面积按倍数平方缩小；放大倍数越大视野越暗、细胞越大、数目越少。
02

细胞的元素与化合物 · 水和无机盐

组成细胞的元素 · 检测生物组织中的糖类、脂肪和蛋白质 · 细胞中的水和无机盐

2.1 组成细胞的元素

  • 大量元素：C、H、O、N、P、S、K、Ca、Mg；微量元素：Fe、Mn、Zn、Cu、B、Mo。
  • C 是最基本元素（碳链构成生物大分子骨架）；鲜重含量最多的是 O，干重含量最多的是 C；占细胞鲜重最多的化合物是水，最多的有机物是蛋白质。
  • 生物界与非生物界的统一性：元素种类大体相同；差异性：元素含量相差很大。

2.2 检测生物组织中的有机物（必背数据）

待测物试剂与配制操作与颜色反应
还原糖斐林试剂：甲液 0.1 g/mL NaOH + 乙液 0.05 g/mL CuSO4，现配现用、等量混合50~65 ℃ 水浴加热约 2 min：浅蓝色 → 棕色 → 砖红色（Cu2O）
蛋白质双缩脲试剂：A 液 0.1 g/mL NaOH 1 mL + B 液 0.01 g/mL CuSO4 3~4 滴不加热，先加 A 液再加 B 液，呈紫色
脂肪苏丹Ⅲ染液（橘黄色）或苏丹Ⅳ染液（红色）切片法需显微镜观察；匀浆法可直接观察，不需显微镜
淀粉碘液变蓝
  • 还原糖：葡萄糖、果糖、麦芽糖、乳糖；蔗糖不是还原糖。选材要求「组织颜色浅、富含待测物」——甘蔗、甜菜（蔗糖非还原糖）、西瓜、番茄（红色干扰）均不合适，常用苹果、梨的匀浆。
  • 双缩脲试剂检测蛋白质要求分子中含两个及以上肽键——二肽不能被检测。

2.3 细胞中的水

  • 存在形式：自由水（良好溶剂、参与反应、运输物质）与结合水（细胞结构的重要组成成分，如与蛋白质、多糖结合）。
  • 自由水/结合水比值：升高 → 代谢旺盛；降低 → 抗逆性（抗寒、抗旱）增强。冬眠动物、越冬植物比值下降。
  • 水的性质：极性分子（良好的溶剂）、液体（氢键缔合）、比热容大（恒温、缓冲温度变化）。
  • 产生水的反应：氨基酸脱水缩合、ATP 合成、有氧呼吸第三阶段、暗反应（糖类合成）；消耗水的反应：多肽水解、有氧呼吸第二阶段、光反应（水的光解）、光合作用的光反应阶段。

2.4 细胞中的无机盐

  • 存在形式：主要以离子形式存在（少量构成化合物，如 Fe2+ 于血红蛋白、Mg 于叶绿素、P 于核苷酸）。
  • 功能：①复杂化合物的组成成分；②维持细胞和生物体的生命活动；③维持细胞的酸碱平衡；④维持细胞的渗透压与形态。
  • 缺乏症：血 Ca²⁺过低→抽搐，过高→肌无力；缺 Fe → 缺铁性贫血；缺 Mg → 叶片变黄；缺 B → 「花而不实」；缺 I → 甲状腺肿大（大脖子病）。
边角小字
  • 血红素：含 Fe²⁺ 的卟啉环辅基；血红蛋白 = 珠蛋白 + 4 个血红素。生物体内没有含 Fe 的氨基酸，Fe 是肽链折叠后与辅基结合的。
  • 等质量的脂肪比糖类含 H 多、含 O 少，氧化分解释放能量多、耗 O 多——脂肪是良好的储能物质。
  • 结合水与抗逆性的关系：结合水比例越高，原生质黏度越大、代谢越慢、抗逆性越强。
易错警示
  • 斐林试剂需现配现用、甲乙液混合后加入，不能像双缩脲那样先后单独加入。
  • 不加热时还原糖与斐林试剂反应极慢（约 50 min 才出现砖红色沉淀），故实验须 50~65 ℃ 水浴加热。
  • 晒干的种子与烘烤干种子：失去的主要分别是自由水和结合水——结合水被破坏后细胞死亡。
  • 「无机盐不提供能量」：无机盐不能作为能源物质。
03

糖类和脂质

细胞中的糖类 · 细胞中的脂质 · 种子成熟与萌发过程中的物质变化

3.1 糖类（主要能源物质）

类别代表物分布与功能
单糖葡萄糖（细胞重要能源）、果糖、半乳糖；核糖、脱氧核糖（构成核酸）不能再水解；葡萄糖是细胞呼吸最常利用的底物
二糖植物：蔗糖（葡萄糖+果糖）、麦芽糖（两分子葡萄糖）；动物：乳糖须水解为单糖才能被吸收；蔗糖、麦芽糖是运输/储存形式
多糖植物：淀粉（储能）、纤维素（细胞壁成分）；动物：糖原（肝糖原、肌糖原）淀粉储能、可水解供能；纤维素不供能，构成植物细胞壁；糖原暂时储能
  • 几丁质（壳多糖）：广泛存在于甲壳类动物和昆虫的外骨骼、真菌的细胞壁中；可用于制作人造皮肤、缝合线等，含 N 元素。

3.2 脂质（C、H、O 为主，有的含 N、P）

类别功能备注
脂肪①细胞内良好的储能物质；②保温；③缓冲、减压，保护内脏等质量产能比糖类多、耗 O 多；动物脂肪饱和程度高、熔点高
磷脂构成所有细胞膜（生物膜）的重要成分脑、卵细胞、大豆中丰富
固醇胆固醇：构成动物细胞膜的重要成分、参与血液中脂质的运输；性激素：促进生殖器官发育与生殖细胞形成；维生素 D：促进肠道对钙和磷的吸收胆固醇过高会导致血管堵塞，但其本身是必需成分，不可完全缺乏

3.3 种子成熟与萌发过程中的物质变化（课件拓展）

  • 油料种子（花生、油菜）成熟过程中：光合产物（糖类）转变为脂肪储存，游离脂肪酸减少、脂肪增多，磷脂含量上升。
  • 种子萌发时：脂肪水解并转变为糖类（经过乙醛酸循环途径），自由水含量增多、呼吸作用增强。
  • 萌发初期干重先增加（吸收 O2 与 H2O 参与氧化，质量来自氧）后持续减少（呼吸消耗）。
边角小字
  • 糖类「甜」与「不甜」与是否为还原糖无关；蔗糖水解产物（葡萄糖+果糖）都是还原糖。
  • 脂肪检测试剂同样可用苏丹Ⅲ/Ⅳ染色后显微镜观察颗粒大小与分布。
  • 植物细胞储能：淀粉；动物细胞储能：糖原和脂肪。纤维素虽然由葡萄糖构成，但不能被人消化（无相应酶）。
易错警示
  • 「糖类是主要能源物质，脂肪是主要储能物质」不要混淆。
  • 所有活细胞都含糖类与脂质；但并非所有细胞都含脂肪（磷脂是膜成分，普遍存在）。
  • 胆固醇过多有害，但缺少会影响膜的稳定性与脂质运输——「胆固醇有害无益」说法错误。

蛋白质和核酸

蛋白质的结构与功能 · 核酸的结构与功能 · 生物大分子以碳链为骨架

4.1 蛋白质（生命活动的主要承担者）

功能（五大类，教材 P28 黑体）

  • 结构蛋白（肌肉、羽毛、头发）；催化（绝大多数酶）；运输（血红蛋白、通道蛋白、载体蛋白）；调节（胰岛素、生长激素）；免疫（抗体）。正常代谢中蛋白质不供能，仅在病理或衰老状态才氧化分解。

基本单位——氨基酸

  • 结构通式：至少含一个氨基和一个羧基连接在同一个碳原子上，该碳原子还连一个氢和一个 R 基。区别在于 R 基不同；有的 R 基中也含氨基或羧基。
  • 组成人体蛋白质的氨基酸约 21 种，其中 8 种（婴儿 9 种）为必需氨基酸，只能从食物获得，人体不能合成；非必需氨基酸可由转氨基作用合成。
  • 必需氨基酸口诀：「携（缬）一（异亮）两（亮）本（苯丙）单（蛋）色（色）书（苏）来（赖）」。
  • 脱水缩合在核糖体上进行：一个氨基酸的羧基与另一个的氨基结合，脱去一分子水，形成肽键（—CO—NH—）。水中 H 来自氨基和羧基，O 只来自羧基。

脱水缩合计算全套公式

肽键数 / 脱去水分子数= 氨基酸数 − 肽链数（链状）= 氨基酸数（环状肽）
至少含氨基 / 羧基数= 肽链数（链状，环状为 0；R 基另计）
N 原子数= 氨基酸数 + R 基中 N 数= 肽键数 + 游离氨基数 + R 基 N
O 原子数= 各氨基酸 O 之和 − 脱去水数（链状）
相对分子质量= Σ氨基酸 − 18 × 脱水数 − 2 × 二硫键数
二硫键由两个半胱氨酸的巯基（—SH）脱 2 个 H 形成
  • 蛋白质结构多样性直接原因：氨基酸的种类、数目、排列顺序不同 + 肽链盘曲折叠形成的空间结构千差万别；根本原因：基因（DNA）的多样性。
  • 肽链间的连接：二硫键、氢键等（肽链间不能形成肽键）；二硫键可存在于肽链内或肽链间。

变性与盐析

  • 变性：高温、过酸、过碱、重金属、酒精等破坏空间结构（肽键不断裂），失去活性且不可恢复；变性后仍能用双缩脲试剂检测。高温消毒灭菌、熟鸡蛋易消化的原理。
  • 盐析：盐溶液降低蛋白质溶解度使其析出，空间结构不变、活性保持，加水可复溶——可逆。低温也不破坏空间结构。

细胞膜与细胞核

细胞膜的结构和功能 · 细胞器与生物膜系统前置知识 · 细胞核的结构和功能

5.1 细胞膜的功能（三条，教材 P40-41）

  • ①将细胞与外界环境分隔开（保障内部环境相对稳定；也是系统的边界）；②控制物质进出（相对性：控制作用有普遍性和相对性）；③进行细胞间的信息交流。
  • 信息交流三种方式：化学物质随体液运输（激素—靶细胞受体）；相邻细胞膜直接接触（精卵识别与结合）；相邻细胞形成通道（高等植物细胞的胞间连丝）。
  • 受体位置：蛋白质类（大分子）激素受体在靶细胞细胞膜上；甲状腺激素（小分子脂溶性）和固醇类激素受体在细胞质或细胞核中。
  • 台盼蓝染色：活细胞不让染料进入（膜的选择透过性），死细胞被染蓝——鉴别细胞死活。

5.2 细胞膜的制备与成分（教材 P42-43）

  • 选材：哺乳动物成熟红细胞——无细胞壁；无细胞核和众多细胞器，排除其他膜干扰；吸水涨破后差速离心得较纯净细胞膜。
  • 成分探索历程：欧文顿（脂溶性物质更易通过 → 膜由脂质组成）→ 戈特、格伦德尔（红细胞膜脂质铺展单分子层面积为表面积 2 倍 → 磷脂连续两层）→ 丹尼利、戴维森（表面张力低于油水界面 → 推测附有蛋白质）→ 后发现糖蛋白（1950s，纽伯格等）、糖脂、糖被。
  • 成分：脂质（约 50%，磷脂最丰富；动物细胞膜还含胆固醇）+ 蛋白质（约 40%）+ 糖类（约 2%~10%，与蛋白质或脂质结合为糖蛋白/糖脂）。功能越复杂的膜，蛋白质的种类和数量越多。

5.3 流动镶嵌模型（教材 P44-45，必背）

  • 磷脂双分子层构成膜的基本支架，具有流动性；蛋白质分子镶、嵌、贯穿（部分或全部嵌入、贯穿于双层，或附着在表面）——分布是不对称、不均匀的。
  • 糖蛋白（糖被）只分布于细胞膜外表面，与细胞识别、信息传递有关——据此判断膜的内外侧。
  • 流动性实例：变形虫运动与摄食、动物细胞缢裂、细胞融合与受精、巨噬细胞吞噬（胞吞）、分泌蛋白与神经递质释放（胞吐）、质壁分离与复原、细胞吸水膨胀失水皱缩。
  • 选择透过性的结构基础：细胞膜上转运蛋白的种类和数量，或转运蛋白空间结构的变化（教材 P66-72）。

5.4 细胞壁（教材 P48）

  • 主要成分：植物——纤维素和果胶；真菌——几丁质；细菌——肽聚糖。全透性（对进出物质无选择性），细胞壁不是系统的边界。功能：支持和保护。
  • 去壁方法：酶解法（纤维素酶+果胶酶）——植物细胞吸水不涨破的原因是有细胞壁。

5.5 细胞核（教材 P54-58）

  • 功能（黑体）：细胞核是遗传信息库，是细胞代谢和遗传的控制中心。
  • 结构：核膜（双层膜，外膜连内质网、附核糖体）、核孔（大分子如 mRNA、蛋白质进出的通道，具选择透过性，DNA 不能随意出核，大分子进出需能量）、核仁（与某种 RNA 的合成及核糖体的形成有关）、染色质（DNA+蛋白质，易被碱性染料染成深色）。
  • 染色质与染色体：同一物质在细胞不同时期的两种存在状态——染色质（细丝状，利于复制转录）⇄ 染色体（高度螺旋，利于分裂时平均分配）；前期出现、末期变为染色质。
  • 四个经典实验结论：美西螈核移植——肤色由细胞核控制；蝾螈受精卵横缢——细胞核控制分裂分化；变形虫切割/核移植——细胞核是生命活动控制中心；伞藻嫁接与核移植——形态结构建成由核控制（伞帽形状取决于核）。只做嫁接实验不能完全说明核的作用（假说需核移植验证）。
  • 核质依存：精子和哺乳动物成熟红细胞寿命短；细胞需保持结构完整性。代谢旺盛细胞：核孔数目多、核仁较大。
  • 模型：物理模型（细胞模型、DNA 双螺旋模型）、概念模型、数学模型。照片不是模型；以实物或图画形式直观表达特征的是物理模型。
边角小字
  • 磷脂分子亲水头朝外、疏水尾相对——脂质体药物：脂溶性药物夹在双层疏水尾部之间，水溶性药物包在核心水环境；脂质体与细胞膜融合或被胞吞后发挥药效（教材 P46）。
  • 提取人口腔上皮细胞膜脂质铺单分子层面积 大于 2S（含核膜、细胞器膜等）；哺乳动物成熟红细胞则恰好等于 2S；细菌因无核膜等也接近 2S。
  • 冰冻蚀刻技术（冷冻断裂）：证明膜蛋白镶嵌、贯穿于磷脂双分子层；荧光漂白恢复技术（FRAP）：证明膜蛋白、膜脂可侧向移动（流动性），部分蛋白恢复慢是因被细胞骨架锚定。
  • 脂筏模型：膜上富含胆固醇和鞘磷脂的有序微区——是对流动镶嵌模型的补充，说明膜的不均一性。
  • 「碱性染料」甲紫溶液 pH 小于 7（酸性）：碱性/酸性染色剂按电离后助色基团所带电荷界定，不由溶液 pH 决定。
  • 双小核草履虫有两个核、肌肉细胞多核：维持正常核质比。
  • 亲核蛋白含核定位序列 NLS，经核孔复合体信号识别、载体介导入核；将 NLS 连到非亲核蛋白上也能使其入核——核孔复合体具有选择透过性。
易错警示
  • 细胞膜上受体不是信息交流必需的结构（胞间连丝、胞内受体）；信息交流也不一定通过细胞膜。
  • 膜的选择透过性与磷脂有关：基本支架内部疏水，水溶性分子和离子不能自由通过（屏障作用）。
  • 高倍镜下看不到暗—亮—暗三层结构（需电镜）；电镜下也看不到糖被的动态变化。
  • 叶绿体产生的 ATP 不经核孔进入细胞核（ATP 由载体/易化扩散，且叶绿体 ATP 专供暗反应）。
  • 光学显微镜下洋葱外表皮细胞的细胞核不易清晰观察（与液泡重叠）。
  • 核孔对物质进出有选择性；mRNA 出、蛋白质（如 DNA 聚合酶、组蛋白）进。

6.1 细胞质与细胞骨架（教材 P47-50）

  • 细胞质 = 细胞质基质（胶质状，细胞代谢的主要场所，含水、无机盐、脂质、糖类、氨基酸、核苷酸、多种酶）+ 细胞器。
  • 分离细胞器的方法：差速离心法——细胞核最先沉淀，依次为叶绿体、线粒体与溶酶体、内质网与高尔基体，核糖体最后。
  • 细胞骨架：由蛋白质纤维组成的网架结构；功能：维持细胞形态、锚定支撑细胞器，与细胞运动、分裂、分化及物质运输、能量转化、信息传递等密切相关。

6.4 分泌蛋白的合成与运输（教材 P51-52，必背）

途径：核糖体（附着型，氨基酸脱水缩合）→ 内质网（初步加工，肽链折叠组装糖基化）→ 囊泡 → 高尔基体（进一步加工分类包装）→ 囊泡 → 细胞膜 → 胞吐。全过程跨膜 0 层，需能量，不需转运蛋白。
  • 研究方法：同位素标记（示踪）法（3H 标记亮氨酸注入豚鼠胰腺腺泡细胞），放射性依次出现于：核糖体 → 内质网 → 高尔基体 → 细胞膜 → 分泌物。
  • 参与分泌蛋白合成的 4 个细胞器：核糖体、内质网、高尔基体、线粒体；5 个有关结构：+ 细胞膜；3 个直接相关的膜结构：内质网膜、高尔基体膜、细胞膜。
  • 膜面积变化：内质网减少；高尔基体先增后减（基本不变）——膜流的交通枢纽/转化中心；细胞膜增加。
  • 需要内质网和高尔基体加工的蛋白：分泌蛋白（消化酶、抗体、蛋白类激素、细胞因子）、膜蛋白、溶酶体水解酶。

6.5 生物膜系统（教材 P53）

  • 组成：细胞膜、核膜 + 细胞器膜（内质网、高尔基体、溶酶体、液泡、线粒体、叶绿体等）。核糖体和中心体无膜，不属于生物膜系统；原核生物有生物膜（细胞膜）但无生物膜系统。
  • 功能（三条必背）：①使细胞具有相对稳定的内部环境，同时在物质运输、能量转换和信息传递中起决定作用；②广阔的膜面积为多种酶提供大量附着位点；③使各类细胞器分工协作、把各种反应分隔开，保证高效有序进行。
  • 结构联系：直接联系（内质网膜→核膜外膜、细胞膜；内质网腔与高尔基体囊泡间接联系）；功能联系：分泌蛋白的合成运输体现。

6.6 实验：用高倍镜观察叶绿体和细胞质的流动（教材 P49）

  • 原理：叶绿体绿色、扁平椭球形，不需染色可直接观察；观察细胞质流动以叶绿体运动为标志。活细胞的细胞质处于不断流动状态（环流式）。
  • 选材：黑藻幼嫩小叶、藓类叶片或菠菜稍带叶肉的下表皮（叶薄、叶绿体少、易观察）。制片后随时保持有水，防止叶绿体变形。
  • 先低倍镜找细胞，再高倍镜观察；黑藻提前在光照、室温下培养可提高流速。同一细胞中叶绿体流动方向一致；若显微镜下顺时针环流，实际也是顺时针（显微镜不上下颠倒旋转方向）。
  • 意义：细胞质流动为细胞内物质运输创造条件，保障生命活动正常进行。
边角小字
  • 显微结构（光镜可见）：细胞壁、细胞质、细胞核、核仁、染色体、叶绿体、线粒体、液泡；亚显微结构（需电镜）：细胞膜、内质网膜、核膜厚度、核糖体、细胞骨架（<0.2 μm）。
  • 溶酶体膜不被自身水解酶分解的可能机制（教材 P48 思考）：膜成分被修饰使酶无法识别；膜所带电荷/特定基团排斥酶；膜转运 H⁺ 维持内部酸性环境（pH≈5）使酶在膜外失活等。
  • 硅肺：吞噬细胞溶酶体缺乏分解硅尘的酶，硅尘破坏溶酶体膜释放水解酶，破坏细胞结构导致死亡。
  • 溶酶体消化底物三来源：自体吞噬（胞内衰老结构）、吞噬体（有害物质）、胞吞（营养物质）；还有自溶作用——衰老细胞靠溶酶体破裂自我消化。初级溶酶体（仅含酶、无底物）→ 次级溶酶体（酶+底物）。
  • 高尔基体顺面膜囊接收内质网来物，KDEL 受体回收逃逸的内质网驻留蛋白（低 pH 促进结合）；反面膜囊 pH 低，负责分类包装。
  • 信号肽假说：分泌蛋白 N 端信号肽引导核糖体附着内质网；蛋白质定位由信号序列（信号肽、线粒体定向肽、核定位信号）决定。
  • ¹⁴C 标记追踪发现：光合作用的产物除糖类外，还有氨基酸和脂类（卡尔文实验中 ¹⁴C 出现于氨基酸和脂类中）；同理细胞分泌的产物也不都是蛋白质。
易错警示
  • 无线粒体一定不能进行有氧呼吸×——好氧细菌（醋酸杆菌等）无线粒体，有氧呼吸酶分布在细胞膜上；蛔虫、哺乳动物成熟红细胞无线粒体，只能无氧呼吸。
  • 一切生物的蛋白质合成场所都是核糖体√（包括病毒寄生时利用宿主核糖体）。
  • 细胞以囊泡运输的不都是蛋白质（如脂质、神经递质）；溶酶体内的水解酶在核糖体合成后须经内质网、高尔基体加工。
  • 葡萄糖不进入线粒体（线粒体膜上无其载体），糖酵解在细胞质基质完成；造血干细胞中葡萄糖运输途径止于细胞质基质。
  • 神经细胞高度分化不再分裂，核 DNA 不复制，DNA 聚合酶不需要运输入核。
  • 大肠杆菌（原核）无内质网、高尔基体；人胰岛素基因导入大肠杆菌后表达产物不能由高尔基体分泌。

细胞的物质输入和输出

渗透作用 · 质壁分离与复原 · 物质跨膜运输的方式 · 影响跨膜运输的因素

7.1 渗透作用（教材 P62，必背第三段）

  • 概念：水分子（或其他溶剂分子）通过半透膜的扩散。方向：双向移动、总体单向。
  • 条件：①具有半透膜；②膜两侧溶液具有浓度差。
  • 半透膜：某些物质可透过而另一些不能透过的多孔性薄膜；选择透过性膜是生物膜，具有选择透过性（活性依赖）。
  • 动态平衡时：水分子仍在进出（数目相等），液面高的一侧浓度仍然较高（水柱压力所致）；浓度指物质的量浓度而非质量浓度。
  • 漏斗实验：蔗糖酶加入后，若单糖不能透过半透膜→液面继续上升后稳定；若单糖能透过→先升后降，最终内外相等。
经典题：等体积等质量浓度的葡萄糖与蔗糖溶液被半透膜隔开——①只允许水通过：葡萄糖一侧（摩尔浓度高）液面升高；②水与葡萄糖可通过、蔗糖不能：先甲高后乙高（葡萄糖先使甲侧升高，后葡萄糖透过使乙侧浓度增大）。

7.3 实验：观察植物细胞的质壁分离与复原（教材 P64-65）

  • 原理：内因——原生质层伸缩性大于细胞壁、原生质层相当于半透膜；外因——外界溶液浓度＞细胞液浓度。
  • 选材：紫色洋葱鳞片叶外表皮（有大液泡、细胞液紫色便于观察）；黑藻（叶绿体绿色可观察）；洋葱内表皮可发生但不宜观察。
  • 试剂：0.3 g/mL 蔗糖溶液——既明显质壁分离又不致细胞失水死亡。引流法：滴蔗糖/清水+吸水纸吸引，重复几次，目的是让细胞浸润在相应溶液中。
  • 三次低倍镜观察、自身前后对照：正常态 → 质壁分离 → 复原。第二次观察时质壁分离首先发生在细胞的角隅处；第一次观察不能省略。
  • 变化分析：失水越多 → 液泡变小、颜色变深、细胞液浓度变大、吸水能力越强；细胞体积略缩小（壁限制）。原生质层与细胞壁之间充满外界溶液（细胞壁全透）。
  • 自动复原：外界浓度＞细胞液浓度先失水质壁分离，但 K⁺、NO₃⁻ 等被主动运输吸收进入细胞，细胞液浓度升高后渗透吸水复原。能自动复原的溶液：KNO₃、甘油、尿素、乙二醇、葡萄糖（0.5 mol/L 尿素先分离后复原；0.3 mol/L 蔗糖只分离不复原）。
  • 应用：①判断细胞死活；②测定细胞液浓度范围；③比较不同细胞液/溶液浓度；④鉴别溶液种类（蔗糖 vs KNO₃）。

7.4 物质跨膜运输的方式（离子与小分子，教材 P66-70）

  • 载体蛋白：只容许与自身结合部位相适应的分子/离子通过，转运时自身构象（空间结构）改变，如 CFTR 蛋白转运 Cl⁻（氯离子大小与性质与其结合部位相适应）。

  • 主动运输类型（能量来源）：ATP 驱动泵（Na-K 泵）、协同转运（离子梯度动力，如 Na⁺-葡萄糖同向转运）、光驱动泵。
  • 胞吞胞吐（大分子等）：依赖膜的流动性，需要膜上蛋白质参与，耗能；跨膜 0 层；运输的不一定是大分子（神经递质小分子也经胞吐）；大分子也可经核孔出（不用胞吞胞吐）。

7.5 影响跨膜运输的因素

  • 物质浓度：自由扩散——在一定范围内速率随浓度增大而增大后达平台；协助扩散/主动运输——需转运蛋白，会饱和。
  • 氧气浓度：自由扩散/协助扩散不受影响；主动运输在有氧呼吸范围内随 O₂ 增大而增大（能量来自呼吸作用），无氧时仍有一定速率（无氧呼吸供能）。
  • 温度：影响膜流动性、酶活性、呼吸供能。载体蛋白数量：限制最大速率。
边角小字
  • 教材 P74-T2：主动运输的机理图——ATP 水解使载体蛋白磷酸化而改变构象（膜上 Na⁺-K⁺ 泵，每消耗 1 个 ATP 运出 3 个 Na⁺、运入 2 个 K⁺）。
  • 小肠上皮细胞吸收葡萄糖：肠腔侧 Na⁺-葡萄糖同向协同转运（主动运输，动力来自 Na⁺ 电化学梯度）；基底侧葡萄糖经载体协助扩散出细胞；Na⁺ 由 Na-K 泵（ATP）泵出。教材 P69 强调：小肠液中氨基酸、葡萄糖浓度远低于细胞内浓度。
  • 蔗糖运入筛管：H⁺ 泵（①）消耗 ATP 建立 H⁺ 梯度，蔗糖- H⁺ 同向转运体（②）借助梯度将蔗糖逆浓度运入筛管——协同转运。
  • 柽柳根系吸收无机盐方式的实验设计：分甲（正常呼吸）、乙（抑制呼吸）两组，比较 Ca²⁺、K⁺ 吸收速率——速率明显不同为主动运输，相同为被动运输。
  • ATP 合酶：H⁺ 顺浓度梯度（协助扩散）返回基质同时催化 ATP 合成；好氧细菌因只有细胞膜，其 ATP 合酶分布在细胞膜上。
易错警示
  • 葡萄糖进出细胞方式不唯一：进红细胞=协助扩散，进小肠上皮=主动运输，进成熟植物细胞（如进导管周围细胞）多为主动运输。
  • 渗透平衡≠两侧浓度相等；液面稳定时高侧浓度仍高。
  • 质壁分离复原实验中，0.5 g/mL 蔗糖浓度过高细胞会因失水过多死亡而不复原。
  • 水分子运输：主要经水通道蛋白（协助扩散），少数经磷脂间隙自由扩散。
  • 主动运输一定耗能，耗能的不一定是主动运输（胞吞胞吐也耗能）；大分子进出核孔不需胞吞胞吐。
  • 「物质逆浓度梯度出入细胞」仅对主动运输；顺浓度也可能需要载体（协助扩散）。

酶与 ATP

降低化学反应活化能的酶 · 细胞的能量「货币」ATP

8.1 酶的本质与作用机理（教材 P78-80）

  • 作用：催化；机理：降低化学反应的活化能（分子从常态转变为容易发生反应的活跃状态所需的能量）。与加热（给反应物能量）机理不同。
  • 本质探索（课本 P79）：巴斯德（发酵与活酵母细胞有关）→ 李比希（酵母死亡裂解后物质起作用）→ 毕希纳（获得无细胞提取液「酿酶」）→ 萨姆纳（提取脲酶结晶，证明是蛋白质）→ 切赫、奥特曼（少数 RNA 也有催化功能）。
  • 酶的概念：活细胞产生的、具有催化作用的有机物，绝大多数是蛋白质，少数是 RNA。
  • 合成原料：氨基酸（CHON）或核糖核苷酸（CHONP）；合成场所：核糖体（蛋白质类）或细胞核（真核生物 RNA 类）；作用场所：细胞内外、体外均可。
  • 鉴定蛋白质类酶：双缩脲试剂（紫色）。

8.2 酶的特性与验证实验

  • 高效性：与无机催化剂相比降低活化能更显著——H₂O₂ 实验：3、4 号对照（Fe³⁺ vs 过氧化氢酶），气泡多、卫生香复燃猛。
  • 专一性：每种酶只能催化一种或一类化学反应。两套方案：①「一底物多酶」淀粉+唾液淀粉酶/蔗糖酶，用碘液检测（蔗糖不与碘反应，不能用碘液检蔗糖是否水解）；②「一酶多底物」淀粉/蔗糖+淀粉酶，用斐林试剂（60 ℃ 保温、沸水浴；不能用碘液，因为碘液无法检测蔗糖是否水解）。
  • 作用条件温和：适宜温度、pH。过酸过碱、高温破坏空间结构永久失活；低温抑制活性但空间结构稳定，升温可恢复——酶保存：低温、最适 pH。
  • 酶促反应原理与催化剂共性：①改变化学反应速率而本身不被消耗；②只能缩短达到平衡的时间，不改变平衡点；③反应前后性质数量不变（但酶自身需要更新）；④都降低活化能。

8.3 探究温度、pH 对酶活性的影响（实验设计细节）

实验要点与「不能」
温度（淀粉+淀粉酶+碘液）冰浴（不变蓝）0 ℃、60 ℃（变蓝浅/消失）、沸水浴（变蓝）三组；先各自保温 5 min 再混合（防止未达预设温度即反应）；沸水浴后自来水冲凉再加碘（100 ℃ 直链淀粉螺旋结构破坏遇碘不变蓝；防止碘蒸发）；不能用 H₂O₂ 酶（加热本身促进 H₂O₂ 分解）；不能用斐林试剂（需加热检测，低温酶活性恢复造成错觉）
pH（H₂O₂+过氧化氢酶）先加酶+不同 pH 溶液（蒸馏水/HCl/NaOH）再加底物（否则未调 pH 反应已结束）；不能用淀粉酶（淀粉在酸性下自行水解；斐林试剂与酸反应干扰；碱性环境碘与碱反应干扰）
  • 酶活性：酶催化特定化学反应的能力，用单位时间内底物减少量或产物生成量表示。
  • 影响因素分两类：温度、pH 通过影响酶活性影响反应速率；酶浓度、底物浓度通过影响酶与底物接触面积影响速率，不影响酶活性。

8.4 激活剂与抑制剂（课件拓展）

  • 激活剂：提高酶活性的物质（无机离子如 Mg²⁺、K⁺、Cl⁻；有机分子如维生素 C、半胱氨酸）。酶原需激活剂激活后才有活性。
  • 抑制剂三种：竞争性抑制——抑制剂与底物结构相似，竞争活性中心；Km 增大、Vmax 不变，增加底物浓度可解除。非竞争性抑制——结合活性中心以外必需基团；Km 不变、Vmax 降低，加底物不能解除。反竞争性抑制——只结合酶-底物复合物（ES）；Km 减小、Vmax 降低。
  • Km（米氏常数）：反应速率达最大速率一半时的底物浓度，反映酶与底物的亲和力（越小亲和力越大）。

8.5 ATP（教材 P87-89）

  • 结构简式 A—P~P~P：A=腺苷（腺嘌呤+核糖）；P=磷酸基团；—普通化学键；~特殊的化学键（远离 A 的那个易断裂，水解释能约 30.54 kJ/mol）。元素：C、H、O、N、P。
  • ATP 彻底水解产物：磷酸、核糖、腺嘌呤；ATP 去掉两个磷酸基团（即 AMP，腺苷一磷酸）是 RNA 的基本组成单位之一（腺嘌呤核糖核苷酸）。
  • 功能：直接的能源物质——糖类、脂肪中能量稳定不能直接利用，须转化为 ATP 中活跃化学能。ATP 是物质不是能量；能口服（被消化分解，意义不大）。
  • ATP 含量少但供能及时持续：ATP 与 ADP 转化迅速且处于动态平衡；该转化机制是生物界的共性。
  • ATP ⇄ ADP + Pi + 能量：不可逆反应——酶不同（水解酶/合成酶）、场所不同、物质可逆而能量不可逆。合成能量来源：动物——呼吸作用；植物——呼吸作用+光合作用。
  • 能量流通：吸能反应与 ATP 水解相联系；放能反应与 ATP 合成相联系。ATP 是细胞内流通的能量「货币」。
  • ATP 产生量与 O₂ 供应量曲线：A 点（无氧时产生少量 ATP，无氧呼吸）；AB 段（O₂ 增多有氧呼吸加强，ATP 上升）；BC 段平台（限制因素：酶、ADP、Pi 等）。哺乳动物成熟红细胞曲线为水平直线（只无氧呼吸）。
边角小字
  • 高中阶段常见酶的功能（背诵）：溶菌酶（溶解细菌细胞壁）；果胶酶（分解果胶、澄清果汁）；胰蛋白酶（伤口愈合、溶解血凝块）；脂肪酶；青霉素酰化酶（改造青霉素为氨苄青霉素）；酪氨酸酶（催化黑色素合成，衰老细胞活性下降）；DNA 聚合酶（单个核苷酸连到 3′-OH，形成磷酸二酯键）；DNA 连接酶（连接 DNA 片段）；限制酶（识别特定序列并断开磷酸二酯键）；解旋酶（断氢键）；RNA 聚合酶（识别启动子、催化转录、兼解旋）；端粒酶（含 RNA 模板的逆转录酶）；DNA 酶（水解 DNA 为脱氧核苷酸）。
  • 能产生激素的细胞一定能产生酶，反之不然；激素与酶共性都调节/催化代谢但不组成细胞结构、不供能；激素不直接参与代谢而是传递调节信息。
  • 哺乳动物成熟红细胞不能产生酶（无核糖体等）；食物中的酶会被消化分解失活。
  • 激素通过 cAMP（第二信使）调节酶活性，或通过细胞内受体促进 mRNA 合成而诱导酶的合成。
  • 教材 P84 相关信息：多数酶最适温度 35~50 ℃，胃蛋白酶最适 pH 1.5~2.0；pH 由 10 降到 1 时胃蛋白酶活性始终为 0（过碱已失活）。
  • 教材 P88 图 5-7：ATP 为主动运输提供能量——载体蛋白磷酸化改变构象。
易错警示
  • 酶能加快反应速率，但不改变平衡点和产率；酶减少产物的说法×。
  • 「加热与酶促反应机理相同」×——加热给反应物能量，酶降低活化能。
  • 酶浓度增大反应速率加快，但酶活性不变；底物浓度同理。
  • 「ATP 与 ADP 相互转化是可逆反应」×——物质可逆、能量与酶不可逆；ADP 结构简式 A—P~P。
  • 「所有酶都在核糖体上合成」×——RNA 类酶不是；「活细胞都能产生酶」×（哺乳动物成熟红细胞不能）。
  • 酶的最适 pH 下加少量盐酸，活性下降；若 pH 恢复，活性可部分恢复（未失活时）；过酸过碱则不可恢复。
  • 低温保存的酶升温后活性恢复，高温处理的酶活性不能恢复。

  • 图甲（酶活性-pH 曲线）+ 图乙（产物量-时间平台）：pH 改变 → 活性点移动但 D（最终产物量）不变、时间变长；温度降低 → E（最适温度）不变、D 不变但斜率变缓；底物量增加 → 最终产物量上移（D 上移）。
  • 瓦堡效应（2020 全国Ⅰ）：癌细胞供氧充足仍主要无氧呼吸，大量吸收葡萄糖；无氧呼吸第二阶段（丙酮酸→乳酸）不产生 ATP。

细胞呼吸

探究酵母菌的呼吸方式 · 有氧呼吸 · 无氧呼吸 · 细胞呼吸原理的应用

9.1 细胞呼吸的概念与实质（教材 P90）

  • 细胞呼吸（黑体）：有机物在细胞内经过一系列的氧化分解，生成二氧化碳或其他产物，释放能量并生成 ATP 的过程。实质：氧化分解有机物、释放能量。
  • 与体外燃烧相比：有氧呼吸条件温和；能量逐步释放；一部分储存在 ATP 中。意义：能量逐步转移到 ATP、充分利用；缓慢有序释放维持细胞相对稳定。

9.2 探究酵母菌细胞的呼吸方式（教材 P91-92）

  • 酵母菌：真核单细胞真菌，兼性厌氧，繁殖（出芽生殖为主），细胞壁+细胞膜+细胞核+液泡+线粒体。
  • 方法：对比实验法（有氧、无氧装置相互对照）。检测 CO₂：澄清石灰水变浑浊；溴麝香草酚蓝水溶液：蓝→绿→黄（由变黄时间长短判断 CO₂ 多少）。检测酒精：酸性（浓硫酸）重铬酸钾：橙色→灰绿色。
  • 装置要点：空气先经 NaOH 溶液（除去 CO₂，排除干扰）；B 瓶（无氧组）先封口放置一段时间耗尽 O₂ 再连通检测瓶；培养液煮沸灭菌（排除杂菌呼吸干扰）；检测酒精需过滤取滤液（培养液浑浊有色会干扰，且葡萄糖可被重铬酸钾氧化产生类似颜色）。
  • 有氧组气泵间歇通空气保证供氧；无氧组可加石蜡油/植物油液封。

9.3 有氧呼吸（教材 P92-93）

阶段场所反应物 → 产物能量
第一阶段细胞质基质葡萄糖 → 2 丙酮酸 + [H](NADH)少量 ATP（少量能量）
第二阶段线粒体基质丙酮酸 + H₂O → CO₂ + [H]少量 ATP
第三阶段线粒体内膜[H] + O₂ → H₂O大量 ATP（最多）
总反应式C6H12O6 + 6O2 + 6H2O →(酶) 6CO2 + 12H2O + 能量
元素去向CO2 中 O：来自葡萄糖和水H2O 中 O：来自 O2；H：来自葡萄糖和水
转移路径C：葡萄糖 → 丙酮酸 → CO218O2 → H218O（第三阶段产物）
  • [H] 是 NADH（还原型辅酶Ⅰ），来源于第一、二阶段，只在第三阶段被消耗（与 O₂ 结合）。
  • 有氧呼吸第三阶段机理：电子传递链（NADH→…→O₂），电子传递释放能量驱动 H⁺ 泵至膜间隙建立梯度，H⁺ 经 ATP 合酶回流推动 ATP 合成；电子供体 NADH、受体 O₂。

9.4 无氧呼吸（教材 P94）

产酒精型C6H12O6 →(酶) 2C2H5OH + 2CO2 + 少量能量代表：酵母菌、大多数植物细胞
产乳酸型C6H12O6 →(酶) 2C3H6O3 + 少量能量代表：人及动物细胞、马铃薯块茎、甜菜块根、玉米胚、乳酸菌
共同点场所全程在细胞质基质第一阶段与有氧呼吸相同；只在第一阶段产 ATP
  • 无氧呼吸释放能量少的原因：葡萄糖中大部分能量存留在酒精或乳酸中；无氧呼吸释放的能量大部分（其余部分）以热能散失。
  • 不同生物无氧呼吸产物不同的直接原因：酶种类不同；根本原因：控制酶合成的基因不同。

9.5 呼吸方式的判断（高频方法）

  • 据产物：产 H₂O → 一定有有氧呼吸；耗 O₂ → 一定有有氧呼吸；无 CO₂ → 一定为产乳酸无氧呼吸（或死亡）。
  • 据气体：O₂ 吸收量 = CO₂ 释放量 → 只进行有氧呼吸（或同时有产乳酸无氧呼吸）；CO₂ > O₂ → 有氧呼吸 + 产酒精无氧呼吸（差值 = 无氧呼吸释放的 CO₂，差值的一半 = 酒精量）；只无 CO₂ 无 O₂ → 产乳酸无氧呼吸（未死）。
  • 液滴移动法（装置一 NaOH 吸收 CO₂：左移距离 = 有氧呼吸耗 O₂ 量；装置二清水对照：左移 = 耗 O₂ − 放 CO₂，右移 = 放 CO₂ − 耗 O₂）。设死种子（等量灭活）对照排除气压温度物理因素；装置需遮光（绿色材料）；种子需消毒、灭菌。
  • 底物为脂肪时：耗 O₂ > 释放 CO₂（脂肪 H 多 O 少）。

9.6 影响细胞呼吸的因素与应用

  • 内因：遗传因素（不同生物呼吸速率不同；同一植物生殖器官＞营养器官；幼苗、花期速率高）。
  • 外因：温度（影响酶活性）、O₂ 浓度、CO₂ 浓度（高浓度抑制呼吸）、含水量。
  • O₂ 浓度曲线关键点：Q 点只无氧呼吸；P 点无氧呼吸消失；QP 段（不含端点）两种呼吸并存；R 点：有氧呼吸弱+无氧呼吸被抑制，总呼吸最弱，有机物消耗最少——果蔬储存最适。
  • 应用（背诵）：包扎伤口用透气纱布（抑制厌氧菌）；酿酒先通气后密封；花盆松土（促进根有氧呼吸、利于无机盐吸收）；储粮晒干、果蔬低温低氧高 CO₂；破伤风杆菌厌氧需清创；提倡慢跑（避免乳酸堆积）；稻田定期排水（避免无氧呼吸产酒精烂根）；长途运输蔬菜充 N₂、调至 R 点对应 O₂ 浓度。
  • 运动时体内主要呼吸方式仍是有氧呼吸；剧烈运动骨骼肌产乳酸——「能量由乳酸分解提供」×（能量来自葡萄糖分解）。
边角小字
  • 教材 P92 科学方法：对比实验——设置两个或两个以上实验组，通过对结果的分析比较来探究每种因素的作用（有氧组与无氧组相互对照）。
  • 教材 P94 小字：细胞呼吸对生物体的意义——为生命活动提供能量，是生物体代谢的枢纽（糖类、脂质、蛋白质等代谢联系）。
  • 磷酸戊糖途径（2022 山东）：植物细胞 10%~25% 的葡萄糖经此途径产生 NADPH（与呼吸作用的 NADH 不同）、CO₂ 和多种中间产物，可转化为氨基酸、核苷酸——受伤组织修复的原料来源。
  • DNP 解偶联（2022 山东 16）：H⁺ 不经 ATP 合酶回基质 → 梯度消失、ATP 大减、产热增多；低温（4 ℃）使电子传递受阻，消耗葡萄糖增多、产热多。
  • 细胞色素 C：线粒体内电子传递蛋白；泄露入细胞质可诱导细胞凋亡；其泄漏与外膜通透性增高有关。
  • 细胞呼吸只释放 CO₂（如产乳酸无氧呼吸）时不改变装置气压——液滴不动的判断陷阱。
易错警示
  • 「没有线粒体就不能进行有氧呼吸」×；「线粒体能直接利用葡萄糖」×（葡萄糖在细胞质基质分解为丙酮酸后才进入线粒体）。
  • 有氧呼吸第二阶段直接产生 [H] 最多（来源包括第一阶段）；第三阶段产生 ATP 最多但消耗 [H] 也最多。
  • 「无氧呼吸不需要 O₂，最终有 [H] 积累」×（[H] 用于还原丙酮酸）。
  • 「检测到重铬酸钾变灰绿一定产酒精」不完全对（还原性糖如葡萄糖也可使其变色；需过滤除糖干扰）。
  • 人体剧烈运动所需能量主要由葡萄糖（有氧呼吸为主）提供，不是乳酸分解。
  • 水稻烂根：无氧呼吸产酒精毒害细胞——不是乳酸。
  • 呼吸强度判断的关键是看消耗葡萄糖的量，而不是释放 CO₂ 的量。

光合作用与能量转化

捕获光能的色素和结构 · 光合作用的原理和应用 · 化能合成作用

10.1 叶绿体与光合色素（教材 P97-99）

  • 色素提取：色素能溶解在无水乙醇（有机溶剂）中；分离：色素在层析液中溶解度不同，溶解度高者随层析液在滤纸上扩散得快。
  • 步骤细节：加 SiO₂（研磨充分）、CaCO₃（防止研磨中色素被破坏）；研磨迅速（防乙醇挥发）充分（破坏叶绿体释出色素）；过滤用单层尼龙布（滤纸吸附色素、色素分子不易透过）；滤纸条剪两角（防边缘扩散过快使色素带不齐）；画滤液细线要细、直、齐（起点相同），干后重复画 1~2 次（积累色素）；滤液细线不能触及层析液（色素会溶入层析液）；试管口塞棉塞（防层析液挥发）。
  • 结果（从上到下）：胡萝卜素（橙黄色，最快）→ 叶黄素（黄色）→ 叶绿素 a（蓝绿色，最宽/含量最多）→ 叶绿素 b（黄绿色）。类胡萝卜素占 1/3（含 C、H 或 C、H、O），叶绿素占 2/3（含 C、H、O、N、Mg）。
  • 色素功能：吸收、传递、转化光能；叶绿素主要吸收红光和蓝紫光，类胡萝卜素主要吸收蓝紫光；对绿光吸收最少（叶片显绿色）。

10.2 光合作用的探索（教材 P100-102）

  • 恩格尔曼：水绵+好氧细菌，极细光束照射——好氧细菌只向叶绿体被光束照射部位集中，全部曝光时细菌分布在叶绿体所有受光部位。结论：①O₂ 由叶绿体释放，叶绿体是光合作用场所；②叶绿体主要吸收红光和蓝紫光。
  • 希尔反应：离体叶绿体加铁盐（有 H₂O 无 CO₂），光照下放 O₂——说明水的光解与糖的合成不是同一反应；但不能证明 O₂ 中氧全部来自水（未排除叶绿体其他物质干扰、未直接观察氧的转移）。
  • 鲁宾、卡门（同位素标记法，对比实验）：H₂18O 组放 18O₂，C18O₂ 组放 O₂——证明光合作用释放的 O₂ 全部来自水。
  • 卡尔文（小球藻、¹⁴CO₂、双向纸层析）：缩短取样时间至 0.5 s，¹⁴C 首先出现在 3-磷酸甘油酸（C₃）→ 5 s 出现在 RuBP（C₅）和六碳糖——C 的转移路径：CO₂ → C₃ →（CH₂O）/C₅。取样后立即煮沸乙醇杀死小球藻终止反应。
  • 卡尔文发现 ¹⁴C 也出现于氨基酸、脂类——光合产物不只是糖类。

10.3 光合作用的过程（教材 P103-104，必背）

10.5 影响光合作用的因素与应用（教材 P105-107）

  • 外因：CO₂ 浓度、光照强度/光质/光照面积/时间、温度（酶活性，主要制约暗反应）、水、矿质元素（N、Mg、P 等）。内因：色素的数量、酶的数量和活性。
  • 光补偿点：光合强度=呼吸强度（植物需整株光合＞呼吸才能生长）；光饱和点以后限制因素为 CO₂ 浓度、温度等。阳生植物补偿点、饱和点均高；阴生植物均低（连续阴雨时阴生植物受影响小）。
  • 关键指标：真正（总）光合 = 净（表观）光合 + 呼吸消耗。「制造/产生/固定/合成/消耗」为总光合；「吸收/释放/测定/积累」为净光合。
  • 午休现象（盛夏晴天）：温度过高蒸腾过强 → 气孔开放程度减小 → CO₂ 吸收减少 → 光合下降（FG 段），主要影响暗反应。
  • 密闭容器一昼夜曲线：I 点低于 A 点 → 光合＞呼吸，植物生长；高于则不能正常生长。
  • 增产措施：「正其行，通其风」、增施有机肥（微生物分解释 CO₂ 与矿质）、施用碳酸氢铵、合理密植与间作套种（提高光照面积）、温室昼夜温差（白天升温增光合、晚上降温减呼吸）、阴雨天补光。

10.6 化能合成作用（教材 P105）

  • 硝化细菌等：利用体外环境中无机物氧化（NH₃ → HNO₂ → HNO₃）释放的化学能合成有机物。与光合作用同为自养，但能源不同（化学能 vs 光能）。
边角小字（高频细节）
  • 光合作用影响因素实验（教材 P105）：探究光照强度——调整灯与烧杯距离；CO₂ 浓度——吹气时间或不同浓度 NaHCO₃ 溶液；温度——水浴保温；光质——功率相同的不同色光 LED。因变量：圆形小叶片浮起的数量（或浮起相同数量所需时间）。灯与烧杯间加盛水玻璃槽吸热防温度干扰。
  • 秋叶变黄：低温叶绿素合成受阻且易降解，类胡萝卜素稳定显现黄色；变红：可溶性糖积累形成花青素。遮光条件下叶绿素含量升高、叶绿素 a/b 比值降低（适应蓝紫光比例高的阴生环境）。
  • 海洋藻类垂直分布：水层对红橙光吸收多，深水为短波长光——绿藻（浅）、褐藻（中）、红藻（深）。
  • 植物细胞中色素不全在叶绿体：液泡含花青素等；幼嫩茎、果实细胞也含光合色素。
  • 光呼吸：Rubisco 双重活性——CO₂/O₂ 比值高时催化羧化（固定 CO₂），低时催化加氧（光呼吸）。光呼吸消耗 NADPH、ATP 和 C₅，降低光合产量；但强光下可消耗过剩 ATP、NADPH，减轻对叶绿体的伤害。生产上提高 CO₂ 浓度既促进暗反应又降低光呼吸而增产。
  • C4 植物（玉米、甘蔗）：叶肉细胞叶绿体中 PEP 羧化酶（对 CO₂ 亲和力强）固定 CO₂ 成 C₄，「CO₂ 泵」将其运至维管束鞘细胞叶绿体释放 CO₂ 再走 C₃ 途径——干旱时气孔关闭仍能利用低浓度 CO₂，光呼吸低、光合强。
  • CAM 途径（景天科等肉质植物）：夜间气孔开放，CO₂ 固定为苹果酸储存于液泡；白天苹果酸脱羧释放 CO₂ 供暗反应——适应干旱。
  • 微藻 CCM：以 HCO₃⁻ 为主要形式的无机碳库，胞内 CO₂ 浓度可达水中 1000 倍。
  • 光抑制与光保护：光能过剩时光合功能下降（PSⅡ为主要光破坏场所）；四道防线——调整叶片/叶绿体角度减少受光、类胡萝卜素热耗散、PSI 环式电子传递（只产 ATP）、电子分流给 O₂ 生成活性氧后被酶清除。
  • 磷酸转运器受抑制：磷酸丙糖运不出叶绿体 → 暗反应受抑制、淀粉积累、无机磷供应减少抑制光反应。
易错警示
  • 色素分离实验「不属于实验要求」的是了解吸收光谱（教材活动只提取分离）。
  • 希尔的实验不能证明 O₂ 全部来自水；鲁宾-卡门才能。
  • 「光合作用产生的 ATP 远多于呼吸产生」×——两者量级相当（判断题常考）；且叶绿体 ATP 只供暗反应。
  • 「停止光照后暗反应立即停止」×——NADPH、ATP 有少量存量，暗反应可持续短暂进行。
  • 光补偿点是「叶肉细胞」还是「整株」：整株植物光合=呼吸时，叶肉细胞的光合＞呼吸（根等不进行光合）。
  • 「暗反应不需要光」≠「暗反应与光无关」——光反应停止后暗反应失去 NADPH、ATP 供应。
  • 从纵坐标是否过原点判断净/总光合：不过原点（有负值/起点在呼吸速率处）为净。

细胞的增殖

细胞周期 · 有丝分裂各期 · 实验：观察根尖分生区组织细胞的有丝分裂 · 无丝分裂

11.1 细胞增殖与细胞周期（教材 P110-111）

  • 细胞增殖：细胞生长和分裂的过程（物质准备+细胞分裂）；是生物体生长、发育、繁殖、遗传的基础。
  • 细胞不能无限长大的原因：①表面积与体积之比（相对表面积）限制——体积越大相对表面积越小，物质运输效率越低；②核质比限制——一个核的控制能力有限。细胞也不能太小（容纳必要结构与物质）。
  • 细胞周期（黑体）：连续分裂的细胞，从一次分裂完成时开始，到下一次分裂完成时为止；包括分裂间期（约占 90%~95%）和分裂期（M 期）。有丝分裂严格指分裂期。
  • 有细胞周期的细胞：茎形成层、根尖分生区、皮肤生发层、造血干细胞、癌细胞、受精卵、精原/卵原细胞、肝细胞（受刺激后）等；神经细胞、成熟红细胞、叶肉细胞等无。
  • 分裂间期细分：G1（RNA、蛋白质合成，为 S 期准备）、S 期（DNA 复制）、G2（合成微管蛋白等，为 M 期准备）。

11.2 有丝分裂各期特点（教材 P112-113，必背）

时期主要特点
间期完成 DNA 分子的复制和有关蛋白质的合成，细胞适度生长；动物细胞中心粒倍增
前期「膜仁消失显两体」：核膜核仁消失，出现染色体和纺锤体，染色体散乱分布
中期「形定数晰赤道齐」：染色体形态稳定、数目清晰，着丝粒整齐排列在赤道板上——观察染色体最佳时期
后期「点裂数数加均极」：着丝粒分裂，姐妹染色单体分开成为两条染色体，染色体数目加倍，平均移向两极
末期「两消两现重开始」：染色体、纺锤体消失，核膜核仁重现
  • 动植物细胞有丝分裂区别：①前期纺锤体形成方式——动物中心粒发出星射线；植物两极发出纺锤丝；②末期细胞质分裂——动物细胞膜中部内陷缢裂；植物赤道板位置出现细胞板扩展成新细胞壁。区分动植物细胞最可靠依据：细胞质分裂方式（有无细胞板）。
  • 赤道板是假想平面（不存在），细胞板是真实结构（植物末期出现）。
  • 数目变化口诀：DNA 加倍在间期（S 期）；染色体加倍在后期；染色单体形成在间期（复制后）出现于前期、消失于后期；染色体出现于前期（螺旋化）。
  • 有关细胞器：核糖体（间期合成蛋白质）、中心体（动物、低等植物）、线粒体（供能）、高尔基体（植物末期形成细胞壁）。
  • 有丝分裂意义（黑体）：将亲代细胞的染色体经过复制后，精确地平均分配到两个子细胞中，保持亲代和子代细胞之间遗传性状的稳定性。
  • 着丝粒分裂不是纺锤丝牵引的结果：秋水仙素抑制纺锤体形成，后期着丝粒照常分裂、染色体照样加倍——验证方法。

11.3 无丝分裂（教材 P115）

  • 过程：细胞核先延长缢裂为二，然后整个细胞从中部缢裂为二。特点：没有出现纺锤丝和染色体的变化（但有 DNA 复制）；过程简单迅速耗能少，核膜核仁不消失。典型实例：蛙的红细胞（高等植物薄壁组织如胚乳细胞中也常见）。

11.4 实验：观察根尖分生区组织细胞的有丝分裂（教材 P116）

流程：培养根尖（葱/蒜，根长约 5 cm，取 2~3 mm）→ 解离（15% HCl : 95% 酒精 = 1:1，使组织细胞相互分离）→ 漂洗（清水，洗去药液防解离过度）→ 染色（甲紫溶液或醋酸洋红液 3~5 min，使染色体着色）→ 制片（弄碎根尖、压片使细胞分散）→ 镜检。
  • 解离后细胞已死亡——不能观察到连续分裂过程，需移动装片寻找不同时期的细胞。
  • 分生区细胞特点：呈正方形、排列紧密；先低倍镜找分生区，再高倍镜观察；视野中间期细胞最多（间期时间最长——各期细胞数目与该期持续时间成正比）。
  • 选材要求：选分裂期占细胞周期比例大的材料便于观察分裂相。
  • 甲紫溶液是「碱性染料」但 pH 小于 7——碱性/酸性由电离后助色基团所带电荷决定。

11.5 细胞周期调控与同步化（课件拓展）

  • 检验点系统：G1/S 检验点（细胞是否足够大、DNA 是否损伤）、S 期检验点（DNA 复制是否正确）、G2/M 检验点、纺锤体组装检验点（中期——染色体是否都与纺锤体正确连接，如 MAD2 蛋白监控单附着染色体）、分离后检验点（染色体是否到达两极，决定是否胞质分裂）。
  • 原癌基因（调节细胞周期、控制生长分裂进程）与抑癌基因（阻止细胞不正常增殖）协同维持细胞周期正常。
  • 药物：抑制 DNA 复制的抗癌药使细胞停留在间期；秋水仙素抑制纺锤体形成→着丝粒正常分裂但染色体不能移向两极→染色体数目加倍（多倍体育种、中期阻断法）。
  • 同步化方法：①DNA 合成双阻断法（胸苷/TdR 两次阻断，使细胞停在 G1/S 交界）；②秋水仙素中期阻断法；③血清饥饿法（停滞于间期）。
  • CDK1 蛋白（2020 山东）：推动间期→分裂期；DNA 复制未完成时 CDK1 磷酸化失活，复制完成后去磷酸化激活。
边角小字
  • 细胞分裂后子细胞三种去向：①继续增殖（造血干细胞、癌细胞、根尖分生区细胞）；②暂不增殖（肝细胞、记忆细胞，受刺激后重返细胞周期）；③不再增殖（神经细胞、成熟红细胞、叶肉细胞、精子等高度分化细胞）。
  • 温度、pH、射线等通过影响酶的活性影响细胞周期长短。
  • 流式细胞仪：可快速测定细胞 DNA 含量并分选不同细胞群（零分辨率，只测整体参量）。
  • 间期易发生基因突变：DNA 解旋稳定性差；分裂期染色体高度螺旋化，不易突变也不易转录（蛋白质合成少）。
  • 卵细胞大但不分裂不意味运输效率不重要——储存营养供早期发育；原生动物伸缩泡增大膜面积与体积之比；双小核草履虫双核维持核质比。
  • 末端缺失染色体（失去端粒）可形成「染色体桥」（2020 山东）：着丝粒分裂后两极牵引使桥断裂，子染色体缺失——染色体结构变异的一种情境。
易错警示
  • 「细胞分裂间期是决定增殖快慢最关键的时期」√（时间占比大、物质准备在此完成）——S 期开始后分裂活动一旦启动会持续到完成。
  • 染色单体：间期复制后即形成，但「出现」通常指前期螺旋化可见；消失在后期（着丝粒分裂）。
  • 观察有丝分裂看不到「动态连续过程」——解离杀死细胞。
  • 秋水仙素作用于前期（抑制纺锤体形成），但细胞会「停留（染色体形态）在中期」；着丝粒能分裂、染色体不能移向两极。
  • G2 期细胞与 G1 期细胞相比：DNA 含量加倍、染色体数不变。
  • 染色体数=着丝粒数；有染色单体时 DNA 数=染色单体数=2×染色体数。

细胞的分化、衰老和死亡

细胞分化 · 细胞的全能性 · 细胞的衰老 · 细胞的死亡（凋亡与自噬）

12.1 细胞分化（教材 P118-119）

  • 概念（黑体）：在个体发育中，由一个或一种细胞增殖产生的后代，在形态、结构和生理功能上发生稳定性差异的过程。
  • 特点：普遍性（贯穿生命历程）、持久性/稳定性（一般保持分化后状态直到死亡）、不可逆性。
  • 根本原因（实质）：基因的选择性表达（遗传物质 DNA 不变；mRNA、蛋白质种类改变）。
  • 「不变与变」：不变——DNA、tRNA、rRNA、细胞数目（核 DNA）；改变——mRNA、蛋白质种类、细胞形态结构功能。
  • 分化与分裂的关系：分裂是分化的基础，二者相伴相随；分化程度越高，分裂能力一般越低。
  • 意义：使多细胞生物体中的细胞趋向专门化，有利于提高各种生理功能的效率。

12.2 细胞的全能性（教材 P120）

  • 概念（黑体）：细胞经分裂和分化后，仍具有产生完整有机体或分化成其他各种细胞的潜能和特性。
  • 原因：细胞含有本物种的全套遗传信息（全套基因）。条件：①离体；②适宜的营养、激素等条件。标志：发育成完整个体或分化成其他各种细胞。
  • 实例：植物组织培养（植物细胞全能性）；克隆羊多莉（已分化的动物细胞核具有全能性）。种子萌发长成植株不是体现全能性（胚本身是幼体，属正常发育）。
  • 一般规律：分化程度越高，全能性越低；但生殖细胞（卵细胞）分化程度高而全能性较高（孤雌生殖）——特例。
  • 干细胞：全能干细胞（胚胎干细胞，可发育成完整个体）→ 多能干细胞（骨髓造血干细胞）→ 专能干细胞（神经干细胞）；应用：干细胞移植治疗白血病、体外培养组织器官。

12.3 细胞的衰老（教材 P122-124）

  • 特征口诀「一大一小、一多一少、两慢两低」：细胞核体积增大（核膜内折、染色质收缩）、细胞体积变小；色素（脂褐素）积累；水分减少；酶活性降低、代谢减慢；膜通透性改变、物质运输功能降低。
  • 染色质收缩 → 影响 DNA 解旋 → 影响复制与转录。多数酶活性降低，但与衰老相关的酶活性可升高。
  • 自由基学说：异常活泼的带电分子或基团攻击磷脂（破坏生物膜）、DNA（基因突变）、蛋白质（活性下降）→ 细胞衰老。
  • 端粒学说：端粒是染色体两端特殊序列的 DNA-蛋白质复合体；细胞每分裂一次端粒缩短一截，内侧正常 DNA 序列受损 → 细胞活动异常。端粒酶（含 RNA 模板的逆转录酶）可补添端粒（生殖细胞、癌细胞中活跃）。
  • 个体衰老与细胞衰老的关系：单细胞生物——细胞衰老=个体衰老；多细胞生物——个体衰老=细胞普遍衰老的过程，但年轻个体也有衰老细胞，衰老个体也有新生细胞（造血干细胞）。
  • 正常细胞衰老有利于机体自我更新；延缓衰老：合理营养、多运动、多用脑、不吸烟、心情愉悦。

12.4 细胞的死亡（教材 P125-127）

  • 细胞凋亡（黑体）：由基因所决定的细胞自动结束生命的过程（程序性死亡，主动、生理性、对机体有利）。实例：胚胎发育中尾的消失、指间细胞自动死亡、被病原体感染细胞的清除、成熟个体细胞的自然更新。
  • 意义：完成正常发育、维持内部环境稳定、抵御外界干扰。机理：凋亡信号与膜受体结合 → 信号转导 → 凋亡相关基因表达 → DNase 切割 DNA、Caspase 降解蛋白 → 形成凋亡小体 → 被吞噬清除（内容物不释放到内环境）。
  • 细胞坏死：外界不利因素导致的被动死亡，膜破裂内容物释放引发炎症，对机体有害。长期吸烟肺部细胞病变死亡属于坏死。
  • 细胞自噬：细胞「吃掉」自身结构和物质——依赖溶酶体清除变性/错误折叠蛋白、衰老损伤细胞器；养分不足时自噬增强；产物可回收利用；激烈的细胞自噬可能诱导细胞凋亡；随年龄增长肌肉细胞自噬减弱。
  • 白细胞凋亡速率远快于红细胞（白细胞吞噬病菌，功能损伤大）；胚胎期尾的消失与溶酶体有直接关系。
  • 新发现的程序性死亡方式：铁死亡（铁依赖的脂质过氧化，线粒体皱缩、染色质不凝聚）；细胞焦亡（感染时程序性死亡，细胞肿胀破裂释放内容物引发炎症）；铜死亡（2022）；双硫死亡（2023）。
边角小字
  • 端粒细节：人类端粒为六碱基重复序列（TTAGGG）ₙ；每次分裂缩短约 30~200 bp——「末端复制问题」：DNA 聚合酶只能 5′→3′ 合成且依赖引物，后随链末端留下缺口。
  • 衰老细胞核变大的机理：核纤层解聚支撑下降；染色质固缩；体积变小机理：钠钾泵活性下降水分流失、线粒体供能不足、细胞骨架支撑失效。
  • 基因的选择性表达不只发生在分化过程中（同一细胞不同时间、环境下也调整表达谱）；RNA 聚合酶基因在所有活细胞中都表达（管家基因），不能作为分化判断依据。
  • 壁虎断尾再生（器官级再生）不体现细胞全能性；骨髓造血干细胞分化出多种血细胞也不属于全能性（未发育成完整个体）。
  • 成熟红细胞无细胞核、无基因，其衰老死亡不属于基因调控的凋亡。
  • 凋亡与自噬形态区别：凋亡形成凋亡小体（单层膜内陷包裹）；自噬形成双层膜自噬泡与溶酶体融合；凋亡一定导致细胞死亡，自噬不一定。
易错警示
  • 「细胞凋亡由遗传机制决定、与环境因素无关」×——环境因素可诱导凋亡相关基因表达。
  • 「凋亡细胞内酶活性都降低」×——凋亡相关酶（DNase、Caspase）活性升高。
  • 「被病原体感染的细胞死亡属于坏死」×——被病毒感染的细胞被效应 T 细胞诱导清除属于凋亡；病原体直接破坏导致的死亡是坏死（吸烟肺病变死亡为坏死）。
  • 「个体发育中分裂、分化、衰老、凋亡对机体都有积极意义」√；「分化后细胞不能再分裂增殖」×（造血干细胞等仍可分裂）。
  • 「细胞分化程度越高全能性一定越低」存在特例（卵细胞）；「已分化细胞都有全能性」×（需离体+条件才能表达）。
  • 细胞衰老≠个体衰老（多细胞生物）；个体衰老时并非所有细胞都衰老。
